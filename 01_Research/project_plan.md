# Vehicle Performance & Setup Optimizer

## Purpose:
Develop a Python-based engineering tool that investigates how vehicle parameters and setup choices influence vehicle performance.

## The tool will investigate:
- acceleration
- braking
- cornering
- aerodynamic drag
- aerodynamic downforce
- tyre grip
- rolling resistance
- vehicle mass
- power
- gearing
- overall performance

## Long-term goal:
Develop the project from basic physics calculations into an interactive vehicle setup and performance analysis tool.

# CENTRAL ENGINEERING QUESTION

| ----------- | ---------------------------- |
| Vehicle     | Mass                         |
| Power       | Engine/motor power           |
| Drivetrain  | Gear ratios                  |
| Tyres       | Coefficient of friction/grip |
| Aero        | Drag coefficient             |
| Aero        | Frontal area                 |
| Aero        | Downforce                    |
| Environment | Air density                  |
| Resistance  | Rolling resistance           |
| Braking     | Brake force / deceleration   |
| Track       | Straight length              |
| Track       | Corner radius                |
